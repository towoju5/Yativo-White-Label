API

One request, any rail

Every rail shares the same authentication, idempotency and webhook pattern, so a payout integration and a card issuance integration read like the same API.

  • Idempotency keys on every write endpoint
  • Webhooks for status changes across all four rails
  • Sandbox and production share one API surface
POST /v1/payouts
curl -X POST https://api.vaultrail.io/v1/payouts \
  -H "Authorization: Bearer sandbox_key_••••••" \
  -H "Content-Type: application/json" \
  -d '{
    "rail": "spei",
    "amount": "1250.00",
    "currency": "MXN",
    "beneficiary": { "clabe": "032180000118359719" },
    "reference": "invoice-8841"
  }'
